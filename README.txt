WINDMILL SOA — install as a phone / laptop app
1) Make a NEW GitHub repository (e.g. windmill-soa) and upload ALL of these:
   index.html, manifest.webmanifest, sw.js, icons/   (Add file -> Upload files -> Commit)
2) Settings -> Pages -> Branch: main -> Save. Wait 1-2 minutes for the link.
3) Android Chrome: menu -> Install app   |   iPhone Safari: Share -> Add to Home Screen
   Laptop Chrome: install icon in the address bar
