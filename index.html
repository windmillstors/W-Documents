🔑 Change App Password

The new password works on every computer and phone (each one must be online the first time you use it there). The old password stops working everywhere. Use at least 8 characters with letters and numbers.

Backup & Restore

Branch sales, old balances, petty cash, saved items & prices, quotation numbers, overdue / lost-customer notes and the address book are kept in the cloud when it is set up (and always on this computer too). A backup file is still a good idea once in a while.
